# Контракт CLI версии 0.1.0

Команды `analyze`, `plan-move`, `dry-run-move` и `apply-move` образуют последовательное усиление
гарантий. Только `apply-move` изменяет проект и только с явным `--confirm`.

Во всех JSON-ответах верхний уровень содержит `schema_version: 1` и `operation`. Значение операции:
`analyze`, `plan_move`, `dry_run_move` или `apply_move`. Несовместимое удаление или изменение смысла
поля требует новой версии схемы.

| Код | Значение |
| ---: | --- |
| 0 | Команда выполнена |
| 1 | Ошибка входного файла или анализа |
| 2 | Некорректная команда, аргументы или отсутствие `--confirm` |
| 3 | Преобразование безопасно заблокировано до применения |
| 4 | Применение или validation неуспешны; выполнен откат, если он возможен |

Для автоматизации следует использовать одновременно JSON и код процесса. Текстовый вывод
предназначен человеку.

`move` в названии команд версии 0.1.0 означает Extract Implementation: публичная функция остаётся
в исходном файле и делегирует переименованной реализации в новом `.cpp`. Команда не переписывает
существующие call sites и не генерирует новые тесты на уже проверяемое поведение.
